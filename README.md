## Game Overview

Try to survive as long as possible, avoid traps, decaying time, and gather powerups to heal

## How to Run
Built with Processing.
Processing version: 4.0.1
Main sketch and project folder: CrumblyMachines
Required libraries, if any: Sound

Download the material and open via processing, it should automatically open as far as I know; run code, to restart rerun code

## Controls
a/d to move left and right respectively, mouse to shoot

## Required Foundation — 2 Points

### Three Power-Up Types
1. Battery — heal some
2. nuclear fuel — turn health decay to health regen for a while
3. Fuel Core — Massive overheal

### Levels
So far it is an infinite, levelless game
